# kanban

A simple kanban project from my Bachelor's Networking course.

## About

There might be some fiew bugs here and there. Given that the project has already been evaluated, I haven't actively maintained it to fix them. However, feel free to open an issue if you have the time to resolve them - even if I doubt someone bothers.

This project has a documentation (`Documentazione.pdf`) which is written in Italian, as it was the mandatory language for the course. If you need a tranlation, feed it to an LLM.

## Compiling

To compile, just execute the make command, make clean to clean the objects.
